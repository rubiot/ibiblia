# iBiblia 1.1.0

A new workspace for Bible translation and Association, with visual editing, richer reference tools and optional AI assistance. This release is available as a portable package for **Windows 10/11 x64**.

## A clearer workspace

![iBiblia 1.1.0 main window](https://raw.githubusercontent.com/wiki/rubiot/ibiblia/images/1.1.0/en/main-window.png)

- **Start the right project.** A guided wizard supports existing source/destination texts or a new translation with an initially empty destination, with previews and validation before creation.
- **Review progress your way.** Customize status labels, colors and order, filter verses by status, and follow the contextual guide. A state header makes the current reference, selection, Association coverage and unsaved changes easier to see.
- **Navigate more comfortably.** Use chapter links, navigation history and a built-in keyboard shortcut reference. Larger projects benefit from faster navigation and rendering.
- **Personalize the interface.** Choose English or Portuguese, your preferred icon family and the default verse mode.

## Write and format visually

![Visual verse editing](https://raw.githubusercontent.com/wiki/rubiot/ibiblia/images/1.1.0/en/visual-editor.png)

- **Edit the formatted verse.** Apply added-word italics, words of Jesus, Old Testament quotations, underline, strike-through, superscript/subscript, HTML formatting, color and relative font size. Turn a selection into a title or change its level.
- **Keep precise control.** Undo/redo, Unicode copy/paste and a Raw view with theWord tag coloring/completion support detailed editing. Hebrew, Greek and translated text can be displayed together with bidirectional rendering.
- **Keep unaffected Associations.** Text edits retain identifiable untouched Syntagms and their Associations. Review the confirmation if an edit would remove associated members.
- **Add richer translator notes.** Create, format and edit note bodies and markers, and preview notes by hovering over their markers. Verse comments remain available for export as notes.

## Explore translation choices

![Translation memory and occurrences](https://raw.githubusercontent.com/wiki/rubiot/ibiblia/images/1.1.0/en/translation-memory.png)

- **Compare earlier wording.** Translation memory groups source forms, lemmas and Strong's numbers with recorded alternatives and frequencies, identifying the current translation.
- **Read the evidence in context.** Open occurrence lists with the exact associated translation highlighted, follow references, load more results or hover for a quick preview.
- **Keep suggestions useful.** Statistical Association memory stays synchronized with edits and offers better matching across word and apostrophe variants.

## Optional AI assistance — experimental

![AI configuration](https://raw.githubusercontent.com/wiki/rubiot/ibiblia/images/1.1.0/en/ai-configuration.png)

- **Translate and associate.** Request translation, Association, or translation with accompanying Associations; optionally mark words added by the translation.
- **Review before applying a batch.** Compare results with current text, accept/reject individual verses, retry failures and decide how proposed comments are combined. See progress, estimated time and token usage when available.
- **Reuse reviewed examples.** Save project verses as examples for either flow, and customize instructions for your work.
- **Configure once, override when needed.** Machine defaults, project inheritance and flow-specific overrides let projects share settings while retaining their own choices. Supported providers include OpenAI, DeepSeek and Google; the model catalog is editable.

AI requires internet access and your own provider API key; provider charges may apply. Relevant verse text, instructions and selected examples are sent to that provider. Windows keys are stored for the current user and may need reconfiguration on another computer. Human review remains necessary.

## Save, exchange and export

- **Create independent project copies.** Save As writes a `.bib` copy including current changes and opens it when successful.
- **Produce modules and concordances.** Export tagged destination text, interlinears, analytical/synthetic concordances and supported MySword outputs, with richer context/occurrence options and separate remembered destinations for each theWord output type.
- **Update outputs more safely.** Exports prepare their output before publication and provide clearer success/warning reports. Modules open in theWord can be updated when write access permits; reload them when necessary. Conflicting locks are reported.
- **Exchange selected work.** Export/apply `.ibpatch` files with explicit verse selection and status mapping when catalogs differ.
- **Use theWord 7 integration.** This release also improves imports, Association consistency, text-edit persistence and AI cancellation behavior.

## Installing or updating

Download the complete `iBiblia-1.1.0-windows-x64.zip` from [GitHub Releases](https://github.com/rubiot/ibiblia/releases), verify its published SHA-256 and extract it into a writable folder. Keep the executable, runtime libraries, certificate bundle, language files, model catalog and notices together.

Before upgrading, save and close your project, preserve an untouched `.bib` backup and keep the previous application folder. The project extension remains `.bib`, but saved settings and credential migrations should not be assumed compatible with older builds. Preserve your `iBiblia.ini` and customized model catalog when moving to the new application folder.

See the [English installation/update guide](https://github.com/rubiot/ibiblia/wiki/Installation-and-updating-(English)), [Portuguese guide](https://github.com/rubiot/ibiblia/wiki/Instala%C3%A7%C3%A3o-e-atualiza%C3%A7%C3%A3o-(Portugu%C3%AAs)) and [user manuals](https://github.com/rubiot/ibiblia/wiki).
