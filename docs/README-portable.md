# iBiblia 1.1.0 — portable Windows x64 package

## English

For Windows 10/11 x64. Extract the complete ZIP into a writable folder and run `iBiblia.exe`. Keep the supplied executable, DLLs, `cacert.pem`, model catalog, languages, notices and licenses together. No installer is required.

Before updating, save and close iBiblia, back up the closed `.bib` project and keep the previous application folder. Extract this package into a new folder. Copy your old `iBiblia.ini` if you want to retain local preferences; preserve and merge any customized `iBiblia.models.json`. Open a project copy and check representative verses/exports before continuing. New saved metadata and credential migrations may not be understood by older versions.

Projects remain `.bib` files. Global AI defaults are local to the Windows user; API secrets use Windows Credential Manager and do not travel with project copies. AI is optional and experimental, requires internet and a provider key, and sends relevant texts/instructions/examples to the selected provider. Review results; provider charges may apply.

- Manual: https://github.com/rubiot/ibiblia/wiki/User-manual-(English)
- Installation/update: https://github.com/rubiot/ibiblia/wiki/Installation-and-updating-(English)
- Releases/support: https://github.com/rubiot/ibiblia/releases and https://github.com/rubiot/ibiblia/issues

The accompanying `release-manifest.json` identifies the source commit and package contents. Compare the ZIP with the SHA-256 file published on the release page. Third-party details are in `THIRD-PARTY-NOTICES.txt` and `licenses/`.

## Português

Para Windows 10/11 x64. Extraia o ZIP inteiro para uma pasta em que possa gravar e execute `iBiblia.exe`. Mantenha executável, DLLs, `cacert.pem`, catálogo de modelos, idiomas, avisos e licenças juntos. Não é necessário instalador.

Antes de atualizar, salve e feche o iBiblia, faça backup do projeto `.bib` fechado e mantenha a pasta da versão anterior. Extraia este pacote para uma pasta nova. Copie seu antigo `iBiblia.ini` para manter preferências; preserve e incorpore alterações feitas em `iBiblia.models.json`. Abra uma cópia do projeto e confira versículos/exportações antes de prosseguir. Metadados novos e migrações de credenciais podem não ser entendidos por versões antigas.

Projetos continuam sendo arquivos `.bib`. Padrões globais de IA são locais ao usuário do Windows; chaves ficam no Gerenciador de Credenciais e não acompanham cópias do projeto. A IA é opcional e experimental, exige internet/chave de provedor e envia textos, instruções e exemplos pertinentes ao provedor escolhido. Revise os resultados; pode haver cobrança pelo uso.

- Manual: https://github.com/rubiot/ibiblia/wiki/Manual-de-utiliza%C3%A7%C3%A3o-(Portugu%C3%AAs)
- Instalação/atualização: https://github.com/rubiot/ibiblia/wiki/Instala%C3%A7%C3%A3o-e-atualiza%C3%A7%C3%A3o-(Portugu%C3%AAs)
- Versões/ajuda: https://github.com/rubiot/ibiblia/releases e https://github.com/rubiot/ibiblia/issues

O arquivo `release-manifest.json` identifica o commit de origem e o conteúdo do pacote. Compare o ZIP com o SHA-256 publicado na página da versão. Informações de terceiros estão em `THIRD-PARTY-NOTICES.txt` e `licenses/`.
