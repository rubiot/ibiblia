===============================================================================
iBiblia - Changelog & Release Notes
===============================================================================

Version 1.0.0.69 (64-bit Edition) - 2026-10-19
-------------------------------------------------------------------------------
* Native 64-Bit Architecture:
  - Ported iBiblia to native 64-bit Windows (Win64 / x86_64).
  - Fully compatible with 64-bit theWord 7 (theword.64.exe) and dual-architecture SQLite.
  - Linked against 64-bit SQLite 3 (sqlite3.dll) and 64-bit PCRE (pcre64.dll).
  - Cleaned all non-portable pointer and ordinal typecasts (PtrInt) across PCRE and TreeView.
  - Resolved C-runtime entry points (setlocale, malloc, free) via msvcrt.dll.

* Verse Status Filtering & Quick Navigation (Issue #104):
  - Added Bible tree filtering by verse status (Not associated, Associating, Needs review, Associated).
  - Integrated dynamic status descriptions from project metadata.
  - Real-time verse counters showing total matches for each status.
  - Added dedicated navigation buttons (< and >) on the navigation panel.
  - Configured global keyboard shortcuts:
    - F8: Jump to Next filtered verse
    - Shift + F8: Jump to Previous filtered verse

* Word Highlighting & Alignment Fixes:
  - Restored solid yellow highlight on word selection and hover.
  - Fixed auto-selection advance on word association so the yellow highlight automatically jumps to the next unassociated translation word.
  - Resolved TLabel transparency rendering on Windows 10/11.

* Stability & Error Resolution:
  - Fixed Access Violation crash when returning from filtered views back to "All verses".
  - Fixed Access Violation crash when switching UI language to English.
  - Detached recursive event triggers during status list rebuilding to protect verse status integrity.
  - Removed obsolete development breakpoints and hardcoded working directory paths from project files.

* UI & Release Enhancements:
  - Added "What's New in iBiblia" startup popup on first launch of new versions.
  - Added "View Changelog" button to the About dialog.
  - Added contributor credit for Edmund Valdez in the About dialog, changelog, and project metadata.
